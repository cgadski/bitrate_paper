\section{Estimates for the Binomial Coefficient \label{appendix:binomial}}
To estimate \(\ln \binom{N}{k}\), it is helpful to first remember the elementary inequalities
\[
	\left(\frac{N}{k}\right)^k \le \binom{N}{k} \le \left( \frac{e N}{k} \right)^k.
\]
Taking logarithms gives
\[
	k \ln \left(\frac{N}{k}\right) \le \ln \binom{N}{k} \le k \ln \left(\frac{eN}{k}\right),
\]
and so $\ln \binom{N}{k} = k \ln \left(\frac{N}{k}\right) + O(k).$ In the sublinear regime $\ln k \sim \eta\ln N,$ this proves that
$$
\ln \binom N k \sim (1 - \eta) k \ln N.
$$
This is the approximation we need for our asymptotic results. However, to estimate for $\ln \binom N k$ when $k^2 \ll N,$ we can use the finer asymptotic
$$
\ln \binom N k = k \ln \left(\frac{eN}{k}\right) + O(k^2 / N).
$$
If we put $\eta = \ln k / \ln N$ and assume $\eta < 1/2,$ this means that
$$
\ln \binom N k = (1 - \eta) k \ln N + k + o(1)
$$
for large $N.$

One heuristic justification for this finer estimate is to consider a random subset \(Y \subseteq [N]\) where each element is included independently with probability \(s = k/N\). Then, where
$$
h(s) = - s \ln s - (1 - s) \ln (1 - s) = - s \ln s + s + O(s^2)
$$
is the binary entropy function, the entropy of \(Y\) is
\begin{align*}
	H(Y) & = h(s) N = - s N \ln s + s N + O(s^2 N) \\
	     & = k \ln \left(\frac{eN}{k}\right) + O\left(\frac{k^2} N\right).
\end{align*}
We expect that for large $N$ the number of elements in $Y$ concentrates sharply around $k,$ and so $H(Y)$ should be close to $\ln \binom N k.$

Indeed this is true. One simple approach is to use Stirling's approximation
$$
\ln n! = n \ln n - n + \frac{1}{2} \ln(2\pi n) + O(n^{-1})
$$
to derive
\begin{align*}
\ln \binom{N}{k} &= \ln N! - \ln k! - \ln(N-k)! \\
&= k \ln \frac{N}{k} + (N-k) \ln \left(1 + \frac{k}{N-k}\right) + O\left(\frac 1 N\right).
\end{align*}
For $k \ll N$, we have
$$
\ln\left(1 + \frac{k}{N-k}\right) = \frac{k}{N} + O\left(\frac{k^2}{N^2}\right).
$$
Overall this proves that
$$
\ln \binom{N}{k} = k \ln \left(\frac{eN}{k}\right) + O\left(\frac{k^2}{N}\right).
$$
